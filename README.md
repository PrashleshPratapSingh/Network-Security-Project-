# Network Security Project

This repository contains a blueprint for a team-based Intrusion Detection System (IDS) project using two complementary approaches.

## Problem Statement
Design and compare two IDS approaches:
- **Approach 1 (Signature-based detection)**
- **Approach 2 (Anomaly-based detection)**

Evaluate both approaches on standard network security datasets and document the comparative results.

## Approach Summary
- **`approach1-signature/`**: Rules/signature based detection pipeline and experiments.
- **`approach2-anomaly/`**: ML/statistical anomaly detection pipeline and experiments.
- **`datasets/`**: Dataset links, notes, and lightweight samples only (no large raw files).
- **`results/`**: Metrics, confusion matrices, ROC curves, screenshots, and comparison charts.
- **`report/`**: Draft report files (LaTeX/Word) and final documentation artifacts.
